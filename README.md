# SaySo

Голосовой помощник для Windows: диктовка в любое окно и голосовые команды. Помощника зовут Мурмур, имя можно сменить. Речь распознаётся прямо на компьютере (Whisper через OpenVINO, лучше всего на Intel NPU), без облака.

- **Диктовка:** держи кнопку, говори, отпусти, и текст появится там, где курсор. Пока диктуешь, его можно править голосом: «удали слово», «новая строка», «замени … на …».
- **Команды:**
  - звук, яркость, программы и игры;
  - поиск файлов по всему диску, скриншоты;
  - Телеграм, погода, курсы валют, таймеры и напоминания.
- **Разговор:** «давай поговорим», если подключена языковая модель (подойдёт бесплатный Gemini).
- **Свои команды и плагины.**
- **MSI Claw:** мощность, вентиляторы, режимы, оверлей и пауза игры голосом через [ClawTweaks](https://github.com/enterTheVoidCode/ClawTweaksCenter). Подсветка стиков через [ClawAmbilight](https://github.com/carbonumbrella/claw-ambilight). Работает и в режиме Xbox.

## Установка

Скачай `SaySo-Setup-<версия>.exe` из [Releases](../../releases) и запусти. Нужна Windows 11 x64. Установщик сам поставит Python, пакеты и модель распознавания речи под твоё железо (NPU, видеокарта Intel или процессор).

## Связанные проекты

- [ClawAmbilight](https://github.com/carbonumbrella/claw-ambilight): подсветка стиков MSI Claw по картинке на экране. SaySo управляет ей голосом.

## Сборка из исходников

- **Что нужно:** .NET 10 SDK и Inno Setup 6.
- **Как собрать:** запусти `build.cmd`. Получится `publish\installer\SaySo-Setup-<версия>.exe`.
- **Где что лежит:**
  - `src\`: программа в трее (C#, WPF);
  - `python\`: распознавание речи, команды и плагины;
  - `installer\`: установщик.
